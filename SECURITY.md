# Security policy

## Reporting a vulnerability

Please don't open a public issue for security problems. Use GitHub's private
[vulnerability reporting](https://github.com/es6/earnings-bot/security/advisories/new) instead.
You should hear back within a week.

## Leaked tokens

If you run your own copy and your Discord bot token leaks, reset it right away under
**Developer Portal → your application → Bot → Reset Token**. The old token stops working
immediately.
