# Tasks suited to Astra

OpenAI's current model guidance positions Astra for demanding reasoning, coding, research
and computer use, and supports `high` reasoning effort. The work-specific priorities below
are engineering recommendations, not claims that a model guarantees a browser bypass.
[Official Astra model documentation](https://developers.openai.com/api/docs/models/gpt-6-astra),
[OpenAI model-selection guidance](https://learn.chatgpt.com/docs/models?surface=app).

| Priority | Bounded task | Required output / stopping rule |
|---|---|---|
| 1 | Adversarial review of summary evidence/temporal semantics | Frozen source corpus, supported controls and wrong measure/period/basis/currency examples. Every proposed rule must survive those controls and improve audited retention. No paid generation or activation without its own budget and quality gate |
| 2 | Design the next release-time cache/profile experiment | One source family, competing explanations, fixed budget/version/vantage, explicit last-negative/first-positive analysis and promotion criteria. End at a decision or a precise remaining uncertainty |
| 3 | Analyze a new natural IR refusal | Sanitized direct/fallback statuses, source/client age, variant hash, waits and recovery. Distinguish transport, parser, publication and cache causes before proposing an alternate route |
| 4 | Verify surviving test-audit mutations suite-wide | Exact reversible patch, full test selection and raw outcome. Exclude equivalent variants and tests outside the original auditor's group before calling something a gap |

Routine adapters, fixtures, small regressions and CI/PR integration suit the regular coding
model. Higher reasoning effort is most valuable when several plausible explanations or
interacting semantic rules must be separated; it cannot make an unpublished document exist
or a publisher update its backend. Browser/client capability must still be measured.

There is now a narrow, verified local profile-dependent HubSpot access result in
[source diagnostics](source-diagnostics.md). It does not establish a general bypass or
publication advantage. Firefox has not been tested here, so no superiority claim is made.
No Astra subagent or new paid model call is started by this TODO list. International work
remains outside the current scope.
