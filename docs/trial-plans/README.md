# Inert publication-comparison drafts

These files live in documentation, outside the schedule watcher. Their 2099 timestamps and
2098 period patterns are deliberate placeholders. Do not copy them into a live schedule
until the issuer, exact fiscal period, confirmed event window and shared host budget are
checked. No new experiment has been scheduled by adding them.

| Draft | Controlled comparison | What it can establish |
|---|---|---|
| `intel-inert.json` | Canonical CloudFront RSS versus the equivalent encoded path, with one shared pause key | Entry visibility at a real publication transition; distinct cache rows alone establish no lead |
| `bw-inert.json` | Business Wire feed versus a FinancialContent listing | Entry visibility only. Exact canonical wire-ID/body provenance and mirror lag must be verified after a new entry; a matching headline is not a usable report |
| `jpm-inert.json` | Business Wire listing versus the issuer's declared quarterly manifest | Wire entry versus exact press-release PDF link visibility. The manifest matcher reuses production role/host/period/conflict validation and never treats a presentation as the release |

The runner journals entry-scoped matched identities, last negative/first positive timing,
cache headers, content hashes, queues, failures and budget use. `already_present` is steady
state; it must not be counted as a transition. All explicit transfers, connection retries,
redirects and browser turns inside the integrated observer reserve from its durable budget.
The runner follows its deadline and shared backoff and sends no alert or model request.

For JPMorgan, immediately verify the discovered PDF with the existing issuer-news acquisition
path and record the first usable-body receipt separately from manifest visibility. These
drafts do not dynamically download linked documents. A PDF upload or Last-Modified stamp
cannot substitute for that observation. For BW, validate the mirror's exact canonical ID
and substantive report with the existing mirror reader; retain independent wire/SEC controls.

Compute availability intervals from each last negative request and first positive receipt.
Overlapping intervals, clock uncertainty or missing observations do not justify an exact
speed ranking. Promote an access/cache variant only after a measurable benefit at a real
event; retain controls over repeated transitions. No synthetic weekend result proves it.

The existing November 16 GlobeNewswire batches and November 17 NVDA SEC trial are unchanged.
They do not measure JPMorgan, Intel or Business Wire mirror latency.

Before activating any draft, make each route recognize the same known historical release
with temporary historical patterns, then restore the future period. A schema-valid plan
alone does not establish coverage. In particular, JPMorgan's results page is populated by
JavaScript and is not an HTTP listing control: a raw page that never exposes entry-scoped
links would create a false apparent lead. Its wire feed is the draft control instead;
confirm that feed's issuer coverage before choosing the actual event.
